# 共享相册 Demo

这是一个最小可验证 Demo，用来验证多人协作上传、自动人物文件夹整理、按文件夹下载，以及浏览器跨平台访问。

## 运行

```bash
python3 server.py
```

打开：

```text
http://localhost:8000
```

局域网内其他设备可以访问本机 IP，例如：

```text
http://你的电脑IP:8000
```

## 验证路径

1. 创建一个相册。
2. 用上传者 A 上传几张图片。
3. 换上传者 B 再上传几张图片。
4. 服务端使用 OpenCV 检测照片中的人脸，并用归一化人脸特征进行相似度聚类。
5. 没有检测到人脸的照片会进入“未识别人脸”文件夹。
6. 点击任意人物文件夹右上角的“下载”，会得到该文件夹的 zip 包。

## Demo 边界

这个版本先把产品闭环跑通。人物分类已不依赖文件名，而是使用 OpenCV Haar Cascade 做人脸检测，并用人脸灰度特征做 Demo 级聚类。生产版本建议替换为 ArcFace/InsightFace/FaceNet 等更稳定的人脸向量模型，并增加人物合并、拆分、命名和纠错流程。Immich 这类项目可作为后续架构参考，但这个 Demo 暂不依赖外部服务。
